# Justin Marshall Personal Website
### App Tech Stack
    - Express(.js) — Node.js web framework
    - React(.js) — a client-side JavaScript framework
    - Node(.js) — the premier JavaScript web server

## Starting the App

### Frontend
 - Navigate to jm-mern-resume-portal/frontend
 - Run the following command

```
npm run start
```

### Backend
 - Navigate to jm-mern-resume-portal/backend
 - Run the following command

```
npm run dev
```
 - This will turn on the nodemailer service for the Contact Me page

## Testing
    - Navigate to jm-mern-resume-portal/frontend
    - Run the following command

```
npm run test:all
```
    - This will trigger the jest test suites to run
    - These tests will also run as part of the workflow when pushed up to github

## App Structure
### Programmer Persona

- #### General Information
    - This consists of my contact information and also my Github contributions.  It shows a graph depicting how many pushes I do up to my many repos
- #### Current Skill List
    - This shows my current tech stack I am working in for my personal and work related projects
- #### Experience
    - This is my on work experience section broken up by different employers
- #### Education
    - This sections shows my degrees from all the colleges I have graduated from
- #### Full Skill List
    - This shows my complete tech stack containing all the technologies I have worked in in the past.  If you hover over the button it will show you how often I am working in this technology
- #### Dev Books
    - This is a list of my favorite tech books that I have read and reference from time to time in my daily work
- #### Dev Links
    - This is a list of sites that I use to help me code and build my tech abilities

### Artist Persona

- #### Portraits
    - A collection of my portrait paintings using my unique style
- #### Flowers
    - A collection of my flower paintings in various styles
- #### Landscapes/Still Life
    - Some of my landscape and still life paintings
- #### Abstract
    - A collection of my abstract art

### About
    - A section of my website that talks about me and my history in development and art

### Contact Me
    - A form to send emails to my private account so that I may correspond with users inquiring about my development work or art portfolio.
